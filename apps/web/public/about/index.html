ABOUT

Internet history, turned into a daily game.

Internet Timeline is a free browser game about the history of the internet and digital culture. Each daily puzzle asks players to place five events in chronological order.

What topics does it cover?

The question pool includes early networking, the World Wide Web, search engines, email, online communities, ecommerce, social media, smartphones, streaming, gaming, cloud computing, cybersecurity, cryptocurrency and artificial intelligence. For a readable overview of the subject, see the internet history timeline.

How are events sourced?

Each event is stored with an explanation and a source. Primary and institutional sources are preferred when available, including company newsrooms, universities, museums, standards organizations and official project histories. The question pool is reviewed as it grows.

How are daily puzzles made?

Daily decks are deterministic so every player gets the same puzzle. The scheduler avoids recent repeats, same-year collisions and excessive clustering by era or category, while mixing easier and harder events. Read more about the daily timeline-game format.

Built with DailyFoundry.

DailyFoundry is the open-source engine behind the game. The source code is available on GitHub.

Can old puzzles be replayed?

Yes. Visit the puzzle archive to replay previous Internet Timeline challenges.
